# Minecraft 启动器社区版验证清单

## 验证说明

本文档用于验证项目开发完成后的功能验收。每个检查项对应一个或多个开发任务,验证通过后方可标记为完成。

---

## 第一部分: 基础设施验证 (10 项)

### 1.1 项目结构验证

- [ ] **项目结构完整**
  - 验证说明: 检查项目目录结构是否符合 Core/Infrastructure/API 分层架构
  - 验证方法: 查看项目文件结构,确认各层职责分离
  - 预期结果: 
    - Core/Domain 层包含业务逻辑和实体
    - Infrastructure 层包含数据访问和外部服务
    - API 层包含控制器和中间件

- [ ] **依赖配置正确**
  - 验证说明: 确认所有 NuGet 包依赖正确配置
  - 验证方法: 运行 `dotnet restore` 检查依赖
  - 预期结果: 无依赖冲突,所有包可正常下载

- [ ] **KMCCC 集成成功**
  - 验证说明: 确认 KMCCC 库正确集成
  - 验证方法: 编译项目,引用 KMCCC 类
  - 预期结果: 无编译错误,可正常使用 KMCCC 命名空间

### 1.2 数据库验证

- [ ] **数据库连接正常**
  - 验证说明: 确认数据库连接配置正确
  - 验证方法: 运行数据库迁移,执行 EF Core 命令
  - 预期结果: 数据库表成功创建,无连接错误

- [ ] **实体映射正确**
  - 验证说明: 确认实体类与数据库表映射正确
  - 验证方法: 查询各表数据,检查字段映射
  - 预期结果: 
    - 所有字段正确映射
    - 关系配置正确(外键/导航属性)
    - 索引正常工作

- [ ] **数据迁移脚本**
  - 验证说明: 确认数据库迁移脚本完整
  - 验证方法: 查看 Migrations 文件夹
  - 预期结果: 
    - 包含所有表的创建脚本
    - 包含初始数据脚本

### 1.3 认证系统验证

- [ ] **JWT Token 生成**
  - 验证说明: 验证 JWT Token 生成正常
  - 验证方法: 调用登录接口,获取 Token

- [ ] **用户注册功能**
  - 验证说明: 验证用户注册接口正常工作
