## 1. 架构设计

纯前端静态网站，无后端服务。

```mermaid
flowchart TD
    A["用户浏览器"] --> B["index.html"]
    B --> C["内联CSS样式"]
    B --> D["内联JavaScript"]

```

## 2. 技术说明

- 前端：纯HTML + CSS + JavaScript（单文件方案）
- 构建工具：无（直接部署静态HTML）
- 后端：无
- 数据库：无
